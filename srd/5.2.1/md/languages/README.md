# Lingue

Ogni file Markdown rappresenta una lingua SRD 5.2.1.

## Frontmatter

Il frontmatter YAML contiene i metadati utili per creazione personaggio: identificatore, nome, categoria e tiro casuale quando previsto.

## Corpo nota

Il corpo conserva il riepilogo leggibile della lingua e una tabella con i dettagli principali.
