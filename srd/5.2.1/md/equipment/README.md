# Equipaggiamento

Ogni file Markdown rappresenta un elemento di equipaggiamento, servizio, veicolo o moneta SRD 5.2.1.

## Frontmatter

Il frontmatter YAML contiene i metadati utili per ricerca, filtri e inventario: identificatore, nome, tipo, categoria, costo, peso e principali campi meccanici quando presenti.

## Corpo nota

Il corpo conserva un riepilogo leggibile e una tabella dei dettagli originali. Le regole generali d'uso restano nelle note di `rules`.
