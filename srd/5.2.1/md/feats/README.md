# Talenti

Ogni file Markdown rappresenta un talento SRD 5.2.1.

## Frontmatter

Il frontmatter YAML contiene i metadati utili per costruzione personaggio: identificatore, nome, categoria, prerequisito ed eventuale ripetibilita.

## Corpo nota

Il corpo conserva il beneficio leggibile del talento. I dettagli meccanici complessi restano nel testo per facilitarne revisione e manutenzione.
