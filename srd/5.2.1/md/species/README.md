# Specie

Ogni file Markdown rappresenta una specie SRD 5.2.1.

## Frontmatter

Il frontmatter YAML contiene i metadati utili per creazione personaggio: tipo di creatura, taglia, velocita e sintesi dei tratti.

## Corpo nota

Il corpo conserva il riepilogo leggibile della specie e, quando presenti nei dati SRD, tabelle per antenati, lignaggi o retaggi.
