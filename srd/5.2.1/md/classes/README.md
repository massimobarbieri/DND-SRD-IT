# Classi

Ogni file Markdown rappresenta una classe SRD 5.2.1.

## Frontmatter

Il frontmatter YAML contiene i metadati utili per ricerca, filtri e costruzione personaggio: identificatore, nome, caratteristica primaria, dado vita, tiri salvezza, competenze, equipaggiamento iniziale e sottoclasse SRD.

## Corpo nota

Il corpo conserva il testo leggibile della classe: panoramica, tratti di classe, progressione, privilegi chiave, lista incantesimi quando presente e sottoclasse. Le tabelle restano nel corpo per facilitarne revisione e manutenzione.
